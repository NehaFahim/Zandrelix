# Zandrelix

> Modern digital experiences powered by technology, creativity, and AI.

Zandrelix is a modern digital agency focused on building high-performance websites, mobile applications, Shopify stores, AI-powered solutions, UI/UX experiences, and custom digital platforms.

This repository contains the source code for the official Zandrelix website.

## ✨ Features

- Modern and premium agency website
- Fully responsive design
- Desktop, tablet, and mobile optimized
- Smooth GSAP animations
- Interactive UI components
- Responsive sticky card interactions
- Magnetic buttons and micro-interactions
- SEO-friendly structure
- Performance-focused Next.js architecture
- Modern dark UI
- Reusable React components
- Scalable component-based architecture

## 🛠️ Tech Stack

- **Next.js**
- **React**
- **TypeScript**
- **Tailwind CSS**
- **GSAP**
- **ScrollTrigger**
- **Lucide React**
- **React Icons**
- **Vercel**

Zandrelix provides:

- AI Solutions
- UI/UX Design
- Custom Digital Platforms
